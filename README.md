# 🤖 Desafio Criativo DIO — Criando um Processo de RPA com N8N e Python

Repositório dedicado ao desafio criativo da [DIO](https://www.dio.me/) sobre **RPA (Robotic Process Automation)** utilizando **N8N** como orquestrador e **Python** para processamento de dados.

---

## 📌 Sobre o Desafio

O objetivo é planejar uma automação de processo (RPA) que una:

- **N8N** — orquestração do fluxo, gatilhos e integrações
- **Python** — leitura, limpeza, validação e transformação de dados
- **Google Drive** — origem dos arquivos
- **PostgreSQL** — destino dos registros consolidados
- **Slack** — alertas e notificações

---

## 🛠️ Automação Planejada

Uma automação para **processar diariamente arquivos de medição enviados por parceiros**, com:

- Validação de dados (duplicatas, datas, campos obrigatórios)
- Inserção idempotente no banco
- Alertas no Slack para anomalias
- Retentativas automáticas em caso de falha de conexão
